# v1.8 原始像素合成规范

这份规范用于解决“场景看起来对了，但商品已经变形、改色或材质不对”的问题。它适用于主图换背景、包装、尺寸敏感商品、印刷/Logo、透明边缘、孔洞、细杆、反光材质和已知的商品保真失败。

## 什么时候必须启用

- 用户要求“保留原始材质”“和原图一致”“只换背景/场景/光影”。
- 商品有 Logo、文字、接口、孔洞、网孔、细杆、金属高光、缝线或易变形边缘。
- 之前的模型结果出现变形、改色、缺件、错字、贴图感或右下角/接触边缘不一致。
- 主图、包装图、尺寸图或重复单元图需要可追溯的商品身份。

人物穿戴、真实承重、拉伸、折叠或产品内部结构无法由单张平面抠图证明时，不要假装原始像素合成已经解决互动问题；应使用匹配的实拍/参考视图，或把结果标为 concept draft。

## 固定流水线

1. **冻结来源**：只从本次输入清单读取原图，记录源文件路径、尺寸、方向和 SHA256；生成结果不得回流为下一槽位的商品参考。
2. **建立锁定商品**：由可靠抠图工具或人工建立 alpha；从原图独立标注 `opaque-core` 和可选的 `keep-open`。不能从同一 alpha 复制出“独立保护区”来伪造检查。
3. **独立检查蒙版**：在黑、白、洋红、绿色、棋盘底和原图局部对照中检查高光、白色材质、细杆、孔洞、毛边、残留背景和白边。用 `matte_guard.py` 记录检查，报告为 draft 时仍必须人工看轮廓。
4. **只生成场景底图**：SalpX 提示词要求连续、无字、无卡片、无占位框的背景/场景底图；明确产品区域不绘制商品本体，或将其作为中性空区。只把 SalpX 的请求/响应 ID 写入运行记录，不写 Key、请求头或 Base64。
5. **本地合成**：把原始 RGB 商品像素按锁定 alpha 放回场景；可在商品外部添加接触阴影、表面反射和局部遮挡。不要让模型生成的商品区域覆盖原始商品，不要透视拉伸、非等比缩放或重绘 Logo/材质。
6. **场景融合**：确认源图机位、支撑面、尺度、受力、光源方向、色温、景深和遮挡关系相容。机位不相容时换场景或补视图，不能用阴影掩盖悬浮、穿模或错误受力。
7. **确定性排版**：先完成无字底图，再添加用户确认的文字、箭头、尺寸、图标和对比标记。模型生成的文字框、标签、卡片和乱码不能作为页面级排版结果。
8. **交付记录**：保存源图、cutout、场景底图、合成图和每槽位 SHA256；记录尺寸、模型、请求 ID、耗时、QA 报告、复核人和剩余风险。

## 最低合成检查

- 商品 RGB 来自源图，而不是模型返回图的商品区域。
- 商品外轮廓、数量、比例、颜色、材质、高光、孔洞、Logo、配件和功能端点与源图一致。
- 商品与场景共用正确的透视、接触面、尺度和光向；没有白边、抠图光晕、悬浮或不可能遮挡。
- 目标尺寸精确匹配槽位要求；重新导出或修改后必须重新计算 QA 与输出 SHA256。
- 任何身份失败都阻断交付，并优先回退到原始像素合成、局部修复或补充源图。
